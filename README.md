# MiniArm Autonomous Pick-and-Place

## Overview

This project documents my development of an Arduino-based 5-DOF robotic arm.

Instead of relying on the manufacturer's firmware, I rewrote the software to better understand embedded systems, motion planning, and robotics.

---

## Current Features

- Manual control of all five servos
- Autonomous pick-and-place routine
- Smooth synchronized interpolation
- Modular C++ code using reusable functions

---

## Hardware

- Arduino Uno
- 5 Servo Motors
- Potentiometer Expansion Board
- ESP32 Camera (future)
